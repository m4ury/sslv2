1. composer install
2. npm i
3. npm install @lucide/vue
4. npx shadcn-vue@latest add table card button input badge
5. renombrar .env.example a .env configurar modificar variables de entorno
6. php artisan key:generate
7. php artisan migrate:fresh --seed / esto generara la estructura de la base de datos y creara un usuario generico: testUser con el correo: test@mail.com y contraseña: test
8. php artisan acceso:administrador test@mail.com para dejar el usuario antes creado como administrador del sistema, se puede cambiar o eliminar después.
9. php artisan lang:publish
10. composer require laravel-lang/common --dev
11. php artisan lang:add es
12. php artisan optimize:clear
13. npm run build
